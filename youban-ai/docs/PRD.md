## 一、产品概述

### 1.1 产品名称

**优伴AI** — AI 驱动的青少年优势成长陪伴平台

### 1.2 产品口号

> 发现天赋，点亮未来 —— 让每个孩子都能成为最好的自己。

### 1.3 产品类型

SaaS 型 AI 教育科技产品，以 Web 应用为主形态，支持多终端（桌面端、平板端、移动端）访问。

### 1.4 目标用户

| 用户角色 | 年龄段 | 核心需求 |
|----------|--------|----------|
| 青少年用户（核心） | 10-18 岁 | 了解自身优势、获得个性化成长指导、养成良好习惯 |
| 家长用户 | 30-50 岁 | 了解孩子发展情况、获取科学育儿建议、参与陪伴成长 |
| 教育工作者 | 25-55 岁 | 辅助教学、了解学生特质、因材施教 |
| 平台管理员 | — | 用户管理、内容运营、数据监控 |

### 1.5 核心理论基础

优伴AI 的产品设计基于以下核心理论框架：

1. **积极心理学（Positive Psychology）** — 马丁·塞利格曼提出的优势发展理论，强调发现和培养个体优势比弥补短板更能带来持久的幸福感与成就感。
2. **多元智能理论（Multiple Intelligences）** — 霍华德·加德纳提出的八大智能维度，为多维评估体系提供理论支撑。
3. **自我决定理论（Self-Determination Theory）** — 强调自主性、胜任感和归属感三大基本心理需求，指导产品互动设计。
4. **成长型思维（Growth Mindset）** — 卡罗尔·德韦克的理论，贯穿成长路径规划与反馈机制。

## 二、核心价值主张

### 2.1 用户价值

- **自我认知升级**：通过科学的多维评估体系，帮助青少年深入了解自身优势、潜能与特质，建立积极的自我认知。
- **个性化成长路径**：基于评估结果，由 AI 生成专属成长计划，告别"一刀切"的教育模式。
- **持续陪伴与激励**：AI 成长伴侣提供 7×24 小时的情感陪伴、正向反馈与成长激励，解决青少年成长中的孤独感与迷茫感。
- **可量化的成长记录**：全周期成长档案让成长"看得见"，帮助用户和家长直观感受进步轨迹。

### 2.2 商业价值

- **教育科技的差异化竞争**：以"优势导向"而非"补差导向"切入市场，形成差异化定位。
- **高粘性产品设计**：成长档案的长期积累特性带来天然的用户留存，配合订阅制商业模式实现可持续营收。
- **数据资产沉淀**：积累的青少年成长数据（脱敏后）可用于教育研究、产品迭代和生态扩展。
- **生态扩展空间**：可延伸至家庭教育咨询、学校合作、内容付费等多元商业场景。

## 三、详细功能需求

### 模块一：多维动态优势评估系统

#### 3.1 功能概述

为用户提供科学、多维、动态的优势评估能力，通过多种评估模式全面了解用户的天赋优势、性格特质和能力倾向，并生成可视化评估报告。

#### 3.2 评估模式

##### 3.2.1 标准化量表评估（Standardized Assessment）

| 功能点 | 详细描述 |
|--------|----------|
| 量表体系 | 基于多元智能理论构建的多维评估量表，涵盖语言智能、逻辑数学智能、空间智能、身体运动智能、音乐智能、人际智能、内省智能、自然探索智能八大维度 |
| 答题流程 | 分步引导式答题，每页展示 1-3 题，支持进度条展示、暂存与恢复、倒计时提示 |
| 防作弊机制 | 答题时间异常检测、一致性校验、随机题序 |
| 智能适配 | 根据用户年龄段自动匹配对应量表版本（10-12 岁 / 13-15 岁 / 16-18 岁） |
| 结果计算 | 实时多维度加权评分，包含信效度指标 |

##### 3.2.2 情境模拟评估（Scenario-Based Assessment）

| 功能点 | 详细描述 |
|--------|----------|
| 情境设计 | 基于真实生活/学习场景设计的情境选择题，考察用户在特定情境下的自然反应倾向 |
| 交互形式 | 图文结合的情境卡片、短视频情境、语音情境（可选） |
| 评估维度 | 问题解决能力、创造力、领导力、协作能力、抗压能力等 |
| 自适应跳转 | 根据用户选择动态调整后续情境，减少题量同时提升评估精度 |

##### 3.2.3 行为观察记录（Behavioral Observation）

| 功能点 | 详细描述 |
|--------|----------|
| 数据采集 | 系统自动记录用户在平台内的关键行为数据：任务完成情况、内容偏好、互动模式、时间分配等 |
| 家长/教师观察输入 | 提供标准化观察量表，由家长或教师填写用户在日常生活中的行为表现 |
| 数据融合 | 将行为数据与量表数据、情境评估数据进行交叉验证和加权融合 |
| 隐私保护 | 所有行为数据采集均需用户（或监护人）授权，数据加密存储 |

#### 3.3 评估报告生成

| 功能点 | 详细描述 |
|--------|----------|
| 总体画像 | 以雷达图直观展示八大维度得分，标注优势领域和潜力领域 |
| 详细解读 | 每个维度的详细文字解读，包含含义说明、得分分析、发展建议 |
| AI 综合评语 | 基于评估结果，由 AI 生成一段个性化、温暖鼓励的综合评语 |
| 对比分析 | 支持与同龄群体平均水平的对比展示（可选匿名群体数据） |
| 报告导出 | 支持 PDF 格式导出，适配打印 |
| 分享控制 | 用户可控制报告的部分或全部内容分享给家长/教师 |

#### 3.4 动态画像迭代

| 功能点 | 详细描述 |
|--------|----------|
| 定期重评提醒 | 系统每 3 个月提醒用户进行重新评估，跟踪优势发展变化 |
| 增量更新 | 结合阶段性的行为数据和轻量评估，持续微调用户画像，无需每次都完整体验完整评估 |
| 成长曲线 | 以时间轴折线图展示各维度得分的历史变化轨迹 |
| 里程碑标记 | 在关键变化节点自动标记并生成解读说明 |

### 模块二：个性化成长路径规划系统

#### 3.5 功能概述

基于用户优势评估结果，智能生成个性化成长目标和行动计划，并追踪执行进度，帮助用户有方向地发展自身优势。

#### 3.6 目标管理

##### 3.6.1 目标设定

| 功能点 | 详细描述 |
|--------|----------|
| AI 推荐目标 | 基于评估结果，AI 自动推荐 3-5 个优先发展目标，附带理由说明 |
| 自定义目标 | 用户可手动创建自定义发展目标，支持 SMART 原则引导填写 |
| 目标分类 | 按维度分类（语言发展、逻辑思维、人际交往等），按周期分类（短期/中期/长期） |
| 目标可视化 | 以目标树或目标地图形式展示目标之间的关联与层级 |
| 家长协同 | 家长可查看目标并提出建议，但最终决策权在用户（青少年）手中 |

##### 3.6.2 目标确认与调整

| 功能点 | 详细描述 |
|--------|----------|
| 确认流程 | 用户确认目标后进入执行阶段，生成专属成长计划 |
| 动态调整 | 支持随时调整目标优先级、截止日期、完成标准 |
| 放弃机制 | 允许用户主动放弃目标，但需填写原因（用于优化推荐算法） |
| 目标归档 | 已完成或放弃的目标自动归档，保留在成长档案中 |

#### 3.7 智能路径拆解

| 功能点 | 详细描述 |
|--------|----------|
| 路径生成 | AI 将每个目标拆解为可执行的阶段性任务（里程碑），每个里程碑包含具体行动项 |
| 任务粒度 | 每个行动项以"天"或"周"为单位，确保可执行性 |
| 资源推荐 | 每个行动项自动关联"优势实践库"中的相关内容（文章、练习、活动等） |
| 难度自适应 | 根据用户完成情况动态调整后续任务难度 |
| 多路径备选 | 为每个目标提供 2-3 条不同侧重点的实现路径供用户选择 |

#### 3.8 进度跟踪

| 功能点 | 详细描述 |
|--------|----------|
| 进度仪表盘 | 以环形进度图展示各目标完成度，按周/月/全部维度切换视图 |
| 任务打卡 | 每日任务完成打卡，支持"已完成/部分完成/未完成"三种状态 |
| 连续记录 | 连续打卡天数统计（Streak），中断后鼓励重新开始 |
| 进度报告 | 每周自动生成周报，汇总本周完成情况、亮点与改进建议 |
| 提醒机制 | 未完成任务在每日固定时间推送提醒（可在设置中自定义） |
| 成就系统 | 完成里程碑后解锁对应成就徽章 |

### 模块三：AI 成长伴侣

#### 3.9 功能概述

AI 成长伴侣是产品的核心差异化功能，通过自然语言对话交互，为用户提供 7×24 小时的陪伴、引导与激励。

#### 3.10 对话交互

##### 3.10.1 对话能力

| 功能点 | 详细描述 |
|--------|----------|
| 多轮对话 | 支持上下文感知的多轮自然对话，理解用户意图和情绪状态 |
| 人格化设定 | AI 伴侣具有温暖、鼓励、积极的人格特质，语言风格适配青少年用户 |
| 话题引导 | 主动引导用户讨论成长相关话题（学习、兴趣、人际、情绪等） |
| 开放式问答 | 支持用户自由提问，涵盖学习方法、情绪管理、人际关系等范围 |
| 安全边界 | 对话内容实时安全过滤，涉及自伤、暴力等风险话题时触发预警并引导至专业帮助 |

##### 3.10.2 对话场景

| 场景 | 说明 |
|------|------|
| 日常闲聊 | 轻松自由的日常交流，建立情感连接 |
| 优势探索 | 围绕评估结果深入讨论，帮助用户理解自身优势 |
| 困难求助 | 用户遇到学习或生活困难时的倾诉与引导 |
| 成就分享 | 用户完成里程碑后主动分享喜悦，AI 给予积极反馈 |
| 情绪疏导 | 感知用户负面情绪，提供温和的情绪疏导和正向引导 |

##### 3.10.3 对话记忆

| 功能点 | 详细描述 |
|--------|----------|
| 用户画像记忆 | 记住用户的核心优势、当前目标、兴趣爱好等关键信息 |
| 对话历史 | 保存完整对话历史，支持按时间、话题检索 |
| 情感状态追踪 | 持续追踪用户情绪变化趋势，在异常时主动关怀 |
| 记忆可控 | 用户可查看、删除 AI 记住的个人信息，保障隐私权 |

#### 3.11 周期性回顾引导

| 功能点 | 详细描述 |
|--------|----------|
| 每日回顾 | 每晚推送简短回顾，引导用户反思当日收获与感受 |
| 每周回顾 | 每周日生成周度成长总结，结合任务完成情况进行深度复盘 |
| 月度回顾 | 每月生成月度成长报告，含 AI 撰写的个性化评语和下月建议 |
| 引导式提问 | 回顾过程采用教练式提问（如"这周你觉得自己在哪方面进步最大？"），引导用户自主思考 |
| 回顾存档 | 所有回顾记录自动归档至成长档案 |

#### 3.12 提醒与激励

| 功能点 | 详细描述 |
|--------|----------|
| 智能提醒 | 根据用户活跃时段智能推送任务提醒，避免打扰 |
| 激励语推送 | 每日推送一条个性化鼓励语或名言，充满正能量 |
| 成就播报 | 达成里程碑后，AI 以拟人化方式"祝贺"用户 |
| 低谷陪伴 | 检测到用户连续未完成任务或情绪低落时，主动发送安慰和鼓励 |
| 激励频率控制 | 用户可自定义提醒和激励的频率与时段 |

### 模块四：优势实践库

#### 3.13 功能概述

提供丰富的实践内容资源，帮助用户将优势认知转化为实际行动，在"做中学"的过程中巩固和发展自身优势。

#### 3.14 内容体系

##### 3.14.1 内容分类

| 类别 | 内容形式 | 说明 |
|------|----------|------|
| 微课程 | 图文 / 短视频 | 5-15 分钟的轻量学习内容，讲解优势发展相关知识与方法 |
| 实践练习 | 交互式练习 | 引导用户完成特定练习（如"今天尝试用3个新词描述自己的感受"） |
| 挑战任务 | 任务卡片 | 具有一定挑战性的实践任务（如"本周主动与一位陌生人交谈"） |
| 阅读材料 | 文章 / 漫画 | 适龄的阅读内容，涵盖人物故事、科普知识、成长感悟 |
| 创意活动 | 活动指引 | 创意类实践活动（如"用绘画表达你的情绪"、"设计一个科学小实验"） |
| 反思模板 | 结构化模板 | 引导用户进行结构化反思（如"今天我最感激的三件事"） |

##### 3.14.2 内容管理

| 功能点 | 详细描述 |
|--------|----------|
| 内容标签体系 | 多维标签：适用维度、适用年龄、难度等级、预估时长、内容类型 |
| 内容审核 | 所有内容上线前需经过专业审核（教育专家 + AI 安全审核） |
| 内容评级 | 根据用户完成后的反馈（喜欢/一般/不喜欢）和完成率动态调整内容推荐权重 |
| 内容更新 | 每周新增内容，保持内容库的持续丰富 |

#### 3.15 智能推荐

| 功能点 | 详细描述 |
|--------|----------|
| 基于优势的推荐 | 优先推荐与用户优势领域和待发展领域匹配的内容 |
| 基于目标的推荐 | 与当前成长目标关联的任务自动推荐相关实践内容 |
| 基于兴趣的推荐 | 根据用户历史互动数据（浏览、完成、收藏）学习兴趣偏好 |
| 新鲜度保持 | 推荐算法平衡相关性与新鲜度，避免信息茧房 |
| 推荐理由 | 每项推荐展示推荐理由（如"基于你的语言智能优势推荐"） |
| 负反馈机制 | 用户可标记"不感兴趣"，算法即时调整 |

#### 3.16 打卡与积累

| 功能点 | 详细描述 |
|--------|----------|
| 一键打卡 | 完成实践内容后一键打卡，记录完成时间和感受 |
| 打卡日历 | 以日历热力图展示打卡频率，月度视图支持回顾 |
| 积分系统 | 完成实践内容获得积分，不同内容类型和难度对应不同积分 |
| 等级体系 | 积分累积升级，解锁不同等级的身份标识和特权 |
| 排行榜 | 可选的匿名排行榜（需用户主动开启），展示积分排名 |
| 积分兑换 | 积分可兑换虚拟装扮、专属内容、实体周边等（后续版本） |

### 模块五：个人中心与成长档案

#### 3.17 功能概述

为用户提供个人账户管理、全周期成长数据归档、数据权益管理等功能，是用户与平台交互的"控制中心"。

#### 3.18 账户与设置

##### 3.18.1 个人资料

| 功能点 | 详细描述 |
|--------|----------|
| 基本信息 | 昵称、头像、年龄、性别、地区（脱敏展示） |
| 账号安全 | 手机号绑定、密码修改、账号注销 |
| 隐私设置 | 个人资料可见范围、评估报告分享权限、行为数据授权范围 |
| 关联账号 | 家长账号绑定/解绑、教师账号关联 |

##### 3.18.2 通知与偏好

| 功能点 | 详细描述 |
|--------|----------|
| 通知管理 | 任务提醒、回顾提醒、激励推送、内容更新通知的开关控制 |
| 免打扰时段 | 自定义免打扰时段（如上课时间、睡眠时间） |
| 语言偏好 | 简体中文（当前版本） |
| 主题切换 | 浅色模式 / 深色模式 / 跟随系统 |
| 字体大小 | 青少年模式（默认大字号）/ 标准模式 |

#### 3.19 全周期成长档案

##### 3.19.1 档案内容

| 档案元素 | 说明 |
|----------|------|
| 评估历史 | 历次评估报告及维度变化趋势 |
| 目标与成果 | 设定过的所有目标、完成的任务、解锁的成就 |
| 实践记录 | 完成的实践内容、打卡记录、积分变化 |
| AI 对话精华 | AI 生成的定期成长总结、关键对话摘要 |
| 自我反思 | 用户的每日/每周回顾记录 |
| 里程碑事件 | 系统自动标记的成长关键节点 |

##### 3.19.2 档案展示

| 功能点 | 详细描述 |
|--------|----------|
| 时间轴视图 | 以时间轴形式展示完整成长历程，支持按年份、月份筛选 |
| 数据可视化 | 趋势图、对比图、占比图等多样化图表展示成长数据 |
| 年度报告 | 每年生成一份精美的年度成长报告（类似"年度听歌报告"风格） |
| 档案导出 | 支持导出完整档案为 PDF 或结构化数据（JSON/CSV） |

## 五、UI/UX 设计规范

### 5.1 视觉设计系统

#### 5.1.1 色彩系统

| 用途 | 色值 | 说明 |
|------|------|------|
| 品牌主色 | `#6366F1`（靛蓝紫） | 代表智慧、创造力与未来感 |
| 品牌辅助色 | `#8B5CF6`（紫色）、`#3B82F6`（蓝色） | 渐变搭配，营造温暖科技感 |
| 功能色-成功 | `#10B981`（翠绿） | 完成、达标、正向反馈 |
| 功能色-警告 | `#F59E0B`（琥珀） | 提醒、待处理 |
| 功能色-错误 | `#EF4444`（红色） | 错误、失败、需要关注 |
| 中性色 | `#F9FAFB` 至 `#111827` 灰度梯度 | 背景、文字、边框 |
| 青少年专属 | 明亮、温暖、饱和度适中的配色 | 避免过于暗沉或刺眼 |

#### 5.1.2 字体系统

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| H1 | 24px | Bold (700) | 页面主标题 |
| H2 | 20px | SemiBold (600) | 模块标题 |
| H3 | 18px | SemiBold (600) | 卡片标题 |
| 正文 | 16px | Regular (400) | 默认正文 |
| 辅助文字 | 14px | Regular (400) | 说明文字、标签 |
| 小字 | 12px | Regular (400) | 脚注、时间戳 |
| 青少年模式 | 默认放大 1 级 | — | 正文 18px 起步 |

#### 5.1.3 图标与插画

- 使用圆润、友好的图标风格，避免尖锐和攻击性视觉元素
- 插画采用温暖、活泼的扁平化风格，角色设计注重多样性
- 加载和空状态使用趣味性动画，缓解等待焦虑
- 成就徽章采用精美插画风格，提升收藏价值感

### 5.2 多设备适配

| 断点 | 宽度 | 适配策略 |
|------|------|----------|
| 移动端 | < 768px | 底部导航栏、单列布局、简化图表 |
| 平板端 | 768px - 1024px | 侧边导航（可折叠）、双列布局 |
| 桌面端 | > 1024px | 固定侧边导航、多列布局、完整功能 |

### 5.3 交互原则

1. **渐进式引导**：新用户首次使用时提供分步引导，非强制可跳过
2. **即时反馈**：所有操作提供即时反馈（动画、提示、状态变化），交互响应时间 < 100ms
3. **容错设计**：关键操作提供确认弹窗，删除操作支持撤销，表单提供实时校验
4. **一致性**：相同功能在不同页面保持一致的交互模式和视觉表现
5. **可访问性**：支持键盘导航、屏幕阅读器友好、足够的颜色对比度（WCAG 2.1 AA）
6. **青少年友好**：避免暗黑模式、恐怖元素、过度商业化表达

### 5.4 情感化设计

| 场景 | 设计策略 |
|------|----------|
| 首次评估 | 温馨的引导动画，强调"这不是考试，没有对错" |
| 评估完成 | 庆祝动画 + AI 温暖评语，强调"你本来就很独特" |
| 任务完成 | 轻快的音效 + 微动画 + 鼓励语，强化成就感 |
| 连续打卡中断 | 温和的鼓励而非责备，强调"重新开始永远不晚" |
| 加载等待 | 趣味性加载动画，附带有趣的小知识或鼓励语 |
| 空状态 | 友好的插画 + 引导文案，避免"空荡荡"的冷感 |
| 错误状态 | 清晰的错误说明 + 解决方案 + 轻松的语气缓解焦虑 |

## 六、非功能性需求

### 6.1 性能需求

| 指标 | 目标值 | 测量方法 |
|------|--------|----------|
| 首屏加载时间 | < 2 秒（4G 网络） | Lighthouse Performance Score ≥ 90 |
| 页面切换时间 | < 500ms | SPA 路由切换耗时 |
| API 响应时间 | P95 < 200ms | 服务端监控 |
| AI 对话响应 | 首字延迟 < 1.5s，流式输出 | 端到端监控 |
| 并发用户 | 支持 1000+ 并发 | 压力测试 |
| 评估报告生成 | < 3 秒 | 端到端计时 |

### 6.2 安全需求

| 需求 | 说明 |
|------|------|
| 数据传输加密 | 全站 HTTPS，TLS 1.3 |
| 数据存储加密 | 敏感数据（密码、个人信息）AES-256 加密存储 |
| 身份认证 | JWT + 刷新令牌机制，支持多设备登录管理 |
| 权限控制 | RBAC 角色权限模型，前后端双重校验 |
| 内容安全 | 用户生成内容（UGC）实时敏感词过滤 + AI 安全审核 |
| 青少年保护 | 符合《未成年人保护法》和《儿童个人信息网络保护规定》要求 |
| 数据脱敏 | 日志和分析系统中对个人信息进行脱敏处理 |
| 渗透测试 | 上线前及每季度进行安全渗透测试 |
| 隐私合规 | 符合《个人信息保护法》（PIPL）要求，提供完整的隐私政策和用户授权流程 |

### 6.3 可用性需求

| 指标 | 目标值 |
|------|--------|
| 系统可用性 | ≥ 99.9%（年度） |
| 故障恢复时间 | < 30 分钟 |
| 数据备份 | 每日全量备份 + 实时增量备份 |
| 灾难恢复 | 支持异地多活或主备切换，RPO < 1 小时，RTO < 4 小时 |
| 灰度发布 | 支持按比例灰度发布，降低发布风险 |
| 服务降级 | 核心功能（评估、成长档案）不受非核心功能故障影响 |
